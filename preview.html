Architecture & Flow Guide

This interactive simulator showcases how HirePath functions across mobile devices. Every screen maps directly to Vue components in src/features/.

1

Hero Auth & Vertical Centering

Powered by LoginView.vue with the hero-scale 96×96px logo, vertical centering flex cluster, Supabase Auth email/password, and Google native/OAuth callbacks.

2

AI Question Generator

In PracticeView.vue, users paste a job description. The Supabase Edge Function generate-questions extracts the tech stack and crafts 3–5 tailored questions.

3

AI Coaching Chat Thread

In SessionDetailView.vue, candidates answer questions and receive instant AI critiques, scoring, and follow-up prompts delivered live via Supabase Realtime.

4

M-Pesa Daraja STK Push

Integrated with Safaricom Daraja API in MpesaModal.vue. Initiates STK pushes, verifies callbacks, activates Pro entitlements, and renders statements in PaymentsView.vue.
